# Giphy

A vanilla JavaScript web app for searching and browsing animated GIFs via the [Giphy API](https://developers.giphy.com/).

## Usage

Open `index.html` in a browser — no install or build step required.

- Click a topic button to load GIFs for that category
- Type a search term and press Enter to add a new topic
- Click any GIF to toggle between its still and animated states

## Tech Stack

- Vanilla JavaScript (ES6)
- jQuery 3.3.1
- Bootstrap 4.3.1
- Giphy API v1

## Project Structure

```
index.html                   # App entry point
assets/
  javascript/main.js         # All application logic
  css/style.css              # Responsive styles
  images/giphy_marks/        # Giphy branding assets
```
